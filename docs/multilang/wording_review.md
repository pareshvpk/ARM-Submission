# Tamil and Hindi wording for review (draft, 2026-11-10)

Status: **DRAFT, not wired into the app.** The owner checks every line. Change anything that sounds unnatural,
too formal, or wrong. Aim: words an older relative would understand at once. Technical words that people already
use in English (OTP, PIN, KYC, SMS, link, app) are kept in English letters on purpose.

How to review: edit the Tamil or Hindi cell in place. Put `OK` in the last column when a row is fine.

Not translated (stay English): app name, model names, timing line, CPU feature line, Llama's own explanation.
