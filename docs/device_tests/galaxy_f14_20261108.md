# Device test: Samsung Galaxy F14 5G, Armv8.0 ExecuTorch build (2026-11-08)

Device: Exynos 1330 (s5e8535: 2x Cortex-A78 + 6x Cortex-A55), 5.3 GiB RAM, CPU features include atomics,
asimddp and fphp. This is the project's development phone; the app was already installed, so the APK (commit
a738ab9, local `executorch-android-1.5.1-armv8.aar`) was upgraded in place with `--user 0` and left installed.
Models already present with matching SHA-256 (no `sms_fp32.pte`, not needed on a dot-product CPU).

Purpose: check that the Armv8.0 baseline library costs no speed on a newer core.

| Measure | Value |
|---|---|
| Cold start TotalTime | 1.29 s |
| Tier and SMS model | FULL, sms_int8.pte (dot product present) |
| Model load | url 89 ms, sms 4561 ms (tokenizer 4232 ms), llama 125 ms |
| Llama settings | FULL: max_new_tokens 130, first token timeout 20 s, total 60 s |

Against earlier F14 numbers with the stock Maven library (`docs/benchmarks.md`: detection 24 to 64 ms warm, prefix
cache TTFT 1332 to 2037 ms, decode 9.2 tok/s in the 2026-11-07 run) the rebuilt library shows no slowdown.
Advice hashes (`advice_sha8`) for messages 1, 3, 4 and 5 equal the Galaxy M32 run, so output is deterministic
across phones.

## Re-test after full-audit round 1 fixes (commit 829f548)

Same six messages, two runs on the same app process setup. Default: `threads_used=4`. `threads.auto`: proposal 2
(the 2x A78 cluster), `threads_used=2` for Llama and both detectors.

| Run | Detect (ms) | TTFT (ms) | Decode (tok/s) | Advice (ms) | Verdicts |
|---|---|---|---|---|---|
| default, 4 threads | 19.9 to 97.5 | 1227 to 2004 | 8.3 to 9.3 | 5525 to 10323 | same six as before |
| threads.auto, 2 threads | 16.6 to 49.8 | 1187 to 1967 | 8.0 to 9.3 | 5516 to 10553 | same six as before |

Advice hashes are identical in both runs (c055eee6, 0994c235, c1d868a5, c6a3c018, 82d407d1). DT-17 (hang with
threads.auto) is fixed. On this 2 big + 6 little core phone, 2 threads on the big cores give the same speed as 4;
the default stays 4 until energy per message is measured with both settings.
