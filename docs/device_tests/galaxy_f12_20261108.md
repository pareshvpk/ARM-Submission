# Device test: Samsung Galaxy F12 (SM-F127G) (2026-11-08)

Device: Exynos 850 (8x Cortex-A55, 2.0 GHz, CPU part 0xd05), 3.6 GiB RAM (MemTotal 3793624 kB), Android 13
(API 33). CPU features include atomics (LSE) but **not** asimddp (no dot product), unlike the Galaxy F14 and the
moto g73. USB powered, Wi-Fi on (the app has no INTERNET permission), battery 39-41 %, 37.4 C at the end.
APK: debug build of commit ba44b2b. Models: the seven files of `models.sha256`, SHA-256 checked on the phone.
Install order: install, launch once so the app creates its own folder, then push models (DT-1 avoided).

Scope rule as in [moto_g73_20261108.md](moto_g73_20261108.md): only `org.ps3.sentinel` was touched; at the end it
was uninstalled and the same leftover checks found nothing (package, Android/data|media|obb folders, ps3_offline
folders, /sdcard msg files, window dump, notifications).

## Findings

All verdicts match the moto g73; nothing crashed. New problems are DT-5 to DT-8 in [PROBLEMS.md](PROBLEMS.md):
SMS detection takes 2.8 to 10.4 s (about 100 to 400 times the moto g73), Llama advice times out on the first two
messages and takes 36 to 40 s otherwise, cold start is 4.5 s, and part of the app is swapped out on 3.6 GiB RAM.
