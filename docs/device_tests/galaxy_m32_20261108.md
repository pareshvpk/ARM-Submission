Device: MediaTek Helio G80 (MT6769V/CT: 2x Cortex-A75 2.0 GHz, CPU part 0xd0a, + 6x Cortex-A55 1.8 GHz, 0xd05),
5.5 GiB RAM (MemTotal 5789028 kB), Android 13 (API 33). CPU features include atomics and asimddp. Battery 64 %,
36.0 C at the end, airplane mode on. APK: debug build of commit ba44b2b; seven model files pushed after a first
launch, SHA-256 checked on the phone (the first Llama push failed with a USB broken pipe and was retried; no
partial file remained).

Scope rule as in [moto_g73_20261108.md](moto_g73_20261108.md). The phone has a second user profile (user 150, for
example Secure Folder); install, grants, launches, force-stop and uninstall all used `--user 0`, and that profile
was not touched. Leftover checks after uninstall found nothing.

## Findings

detection took 1.03 s against 25 to 99 ms for the others (one-off outlier, not tracked). Second user profiles need
`--user 0` in the test scripts (DT-12).
