# Multi-language work (Tamil and Hindi)

This folder started on 2026-11-10 as a local experiment copy of the main project. On 2026-11-15 the owner decided to publish the multi-language work: the copy is now pushed to the same repository as the main project, and the two local folders stay separate.

Never committed (git-ignored): real inbox files (`bench/heldout_ml/real_*`, `docs/multilang/real_*`), raw and processed training data (`data/raw_ml`, `data/processed_ml`), models, `tmp_work/`.

Where things are: plans and results in `docs/multilang/` (start with `RESULTS.md`), evaluation scripts and test sets in `bench/heldout_ml/`, data tools in `data/tools/`, translation and fine-tune kernels in `training/translate/` and `training/finetune_ml/`.
